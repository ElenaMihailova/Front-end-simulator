# Task data

`tasks.ts` contains only sample tasks required to verify the simulator flow. Do not treat this file as a finished curriculum.

The intended workflow is Git-first:

1. Research one frontend interview drill or real layout problem.
2. Add one task object to `tasks.ts`.
3. Write a short prompt in English.
4. Add starter HTML/CSS that matches the task type:
   - `build-from-scratch`: empty canvas or a minimal semantic scaffold.
   - `fix-layout`: intentionally broken HTML/CSS.
   - `responsive`: a working desktop or base state that needs adaptation.
5. Optionally add `sourceUrl`, `referenceSolution`, or `assertions` for personal notes.

Keep task copy short. The app should stay a practice surface, not a theory course, hint system, scoring engine, or generated task library.
